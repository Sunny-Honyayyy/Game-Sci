## 📖 ความเป็นมาของเกม

**เรื่องราวในเกม** เกมนี้จะจำลองให้ผู้เล่นเข้าไปเจอขบวนรถเกวียนของเผ่ายิปซี ที่มีหมอดูทำนายดวงชะตาของผู้เล่นด้วยไพ่ยิปซี สิ่งที่หมอดูทำนายออกมานั้นจะกำหนดดวงชะตาของผู้เล่นกับมหาวิทยาลัยนเรศวรและอนาคตทางสาย IT  จงเลือกให้ถูกต้องเพื่อกำหนดโชคชะตาของตนเอง 

**วัตถุประสงค์** เกมนี้จัดทำขึ้นเพื่อเป็นสื่อการเรียนรู้เชิงปฏิสัมพันธ์ (Interactive Learning Media) โดยแบ่งเนื้อหาออกเป็น 2 โหมดการเล่นหลัก เพื่อให้ผู้เล่นสามารถเลือกทดสอบความรู้ตามหมวดหมู่ที่สนใจ ได้แก่

1.โหมดความรู้เกี่ยวกับมหาวิทยาลัยนเรศวร: มุ่งเน้นการเผยแพร่ประวัติความเป็นมา สัญลักษณ์ อัตลักษณ์ และข้อมูลสำคัญของมหาวิทยาลัยนเรศวร เพื่อสร้างความตระหนักรู้และความภาคภูมิใจ
           
2.โหมดความรู้ด้านเทคโนโลยีสารสนเทศ (IT): มุ่งเน้นการส่งเสริมทักษะและความรู้พื้นฐานด้านเทคโนโลยี สารสนเทศ และคอมพิวเตอร์ เพื่อพัฒนาทักษะดิจิทัลของผู้เล่น
